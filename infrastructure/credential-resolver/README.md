# @founderos/credential-resolver

This package owns the Milestone 18 process-local deterministic synthetic credential boundary.

It resolves only the exact active synthetic rotation version, applies monotonic rotation and permanent revocation, constructs non-provider-valid bytes inside one synchronous closure, and overwrites its owned buffer before returning a strict sanitized port result.

It has no filesystem, environment, Keychain, secret-store, provider SDK, endpoint, header, transport, network, deployment, release, or live-execution capability. State is lost on restart, and buffer overwrite is not a VM, operating-system, or hardware erasure claim.
