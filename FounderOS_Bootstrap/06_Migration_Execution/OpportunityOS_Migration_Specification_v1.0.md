# 1. Purpose

OpportunityOS is the first real project migrated into FounderOS.

The migration transforms:

    OpportunityOS Repository

    +

    ChatGPT Discussions

    +

    Architecture Documents

    +

    Engineering History

    +

    Decision Records

into:

    FounderOS Knowledge Domain

    +

    Knowledge Objects

    +

    Project Memory

    +

    Decision Memory

    +

    Hermes Context

The objective:

> Prove that FounderOS can understand, manage, and improve a real
> AI-native venture.
