# FounderOS Constitution v1.0

## Document Status

Version: v1.0\
Layer: Governance Foundation

## 1. FounderOS Declaration

FounderOS is an AI-native operating system designed to help founders
discover opportunities, make strategic decisions, build products,
operate ventures, and continuously improve through human-AI
collaboration.

FounderOS increases founder leverage by combining human judgment,
accumulated knowledge, and coordinated AI agents.

## 2. Mission

Help founders operate AI-native companies by combining:

-   Human strategic thinking
-   Knowledge systems
-   AI agents
-   Execution workflows
-   Continuous learning loops

## 3. Core Principles

### Human Judgment Sovereignty

Humans retain final authority over:

-   Vision
-   Values
-   Strategy
-   Priorities
-   Irreversible decisions

AI provides analysis and execution support.

### Context Is the Long-Term Moat

AI models are replaceable. Context compounds.

FounderOS preserves:

-   Decisions
-   Reasoning history
-   Project knowledge
-   Lessons learned
-   Operating principles

### Knowledge Is a Strategic Asset

Important:

-   Decisions
-   Experiments
-   Failures
-   Insights
-   Research

should become reusable intelligence.

### Agents Are Workforce Components

Agents are specialized workers inside FounderOS.

Examples:

-   Hermes: Chief of Staff
-   Codex: Engineering
-   OpenClaw: Operations
-   OpenMinis: Device Interface

### Architecture Must Survive AI Evolution

FounderOS must not depend on:

-   One model
-   One vendor
-   One framework
-   One temporary trend

## 4. Operating Philosophy

Observe → Understand → Decide → Execute → Learn → Improve

Every execution should create future intelligence.

## 5. Human-AI Responsibility Boundary

Human owns:

-   Purpose
-   Judgment
-   Values
-   Strategic decisions

AI supports:

-   Research
-   Analysis
-   Automation
-   Execution

## 6. Agent Governance Rules

Agents must:

-   Have defined responsibilities
-   Operate within permissions
-   Maintain execution history
-   Provide traceable outputs
-   Update memory when appropriate

## 7. Knowledge Ownership Rules

FounderOS must ensure:

-   Founder owns knowledge
-   AI assists processing
-   Sources remain traceable
-   Decisions remain explainable

## 8. What FounderOS Will Never Become

FounderOS is not:

-   A chatbot wrapper
-   A prompt collection
-   A generic productivity tool
-   An automation-only platform
-   A replacement for founders
-   A single-model AI product

## 9. Technology Evolution Rules

New technologies must be evaluated by:

1.  Improving founder leverage
2.  Improving context quality
3.  Improving decision quality
4.  Improving execution capability
5.  Preserving architecture independence

## 10. Constitutional Priority Order

Human Judgment

↓

Founder Intent

↓

Knowledge Integrity

↓

System Reliability

↓

Execution Efficiency

## 11. Final Principle

Traditional company:

Founder + Employees + Software

AI-native company:

Founder + FounderOS + AI Workforce
