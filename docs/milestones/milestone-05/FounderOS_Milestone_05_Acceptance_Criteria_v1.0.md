# FounderOS Milestone 05 Acceptance Criteria v1.0

## Functional Criteria

-   [ ] Query contract implemented
-   [ ] Result contract implemented
-   [ ] Context filtering supported
-   [ ] Deterministic evaluation fixtures created

## Quality Criteria

-   [ ] Results preserve provenance
-   [ ] Queries are deterministic

## Non-Goals

The milestone does not include:

-   Embeddings
-   Vector databases
-   Semantic ranking
-   Agents

KnowledgeOS can be queried through stable contracts without depending on
retrieval infrastructure.
