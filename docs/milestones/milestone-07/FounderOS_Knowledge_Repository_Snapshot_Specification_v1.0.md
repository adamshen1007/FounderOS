# FounderOS Knowledge Repository Snapshot Specification v1.0

## Purpose

Define versioned KnowledgeOS repository snapshots.

## Snapshot Contains

- Snapshot ID
- Corpus version
- Source manifest
- Content fingerprint
- Object count
- Creation metadata

## Requirements

Snapshots must be:

- Immutable
- Traceable
- Deterministic

## Principle

Versioned knowledge enables reliable future AI context.
