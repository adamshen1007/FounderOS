# FounderOS Knowledge Object Lifecycle Specification v1.0

## Lifecycle

    Draft
     |
     v
    Validated
     |
     v
    Approved
     |
     v
    Indexed
     |
     v
    Retrieved
     |
     v
    Archived

## Rules

Validated objects require:

-   Schema validation
-   Metadata validation
-   Provenance checks

Approved objects require human review.

## Principle

Knowledge quality improves through controlled lifecycle management.
