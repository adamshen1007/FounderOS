# FounderOS Milestone 17 Acceptance Criteria v1.0

## Decision rule

Milestone 17 is eligible for a commit-ready review only when every criterion below is reproduced
from the exact candidate and all required repository gates pass. This does not authorize
publication or Milestone 18.

## Explicit non-goals

No credential resolution, identity provider, durable or distributed authorization storage,
provider mapper, transport, network request, Agent, Hermes, MCP, UI, deployment, release, or live
execution is accepted in Milestone 17.
