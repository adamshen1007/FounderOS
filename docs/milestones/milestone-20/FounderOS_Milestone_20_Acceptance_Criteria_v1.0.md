## Non-Goals

No real credential, secret store, material handoff, authentication header, live final pre-send gate,
DNS, TLS, socket, HTTP, provider SDK, provider request, production model, external observability,
deployment, release, durable/distributed M20 state, Agent, Hermes, MCP, UI, or later-milestone
authority is accepted.
