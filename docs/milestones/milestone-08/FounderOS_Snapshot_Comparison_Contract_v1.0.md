# FounderOS Snapshot Comparison Contract v1.0

## Purpose

Define comparison between KnowledgeOS snapshots.

## Input

-   Current snapshot
-   Proposed snapshot

## Output

A Change Set containing:

-   Added objects
-   Removed objects
-   Modified objects
-   Metadata changes
-   Provenance changes

## Requirements

Comparison must be:

-   Deterministic
-   Explainable
-   Provenance preserving

## Principle

Every knowledge change should have an understandable reason.
