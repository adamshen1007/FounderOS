# FounderOS Knowledge Change Set Model v1.0

## Purpose

Define the representation of knowledge changes.

## Change Set Contains

-   Change ID
-   Source snapshots
-   Added objects
-   Removed objects
-   Modified objects
-   Review status

## Change Types

Added: New knowledge objects.

Removed: Objects removed from active corpus.

Modified: Objects with changed content, metadata, relationships, or
provenance.

## Principle

Knowledge changes should be explicit and auditable.
