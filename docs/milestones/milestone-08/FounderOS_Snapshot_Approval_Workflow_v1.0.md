# FounderOS Snapshot Approval Workflow v1.0

## Workflow

    Generate Snapshot

    ↓

    Validate

    ↓

    Compare

    ↓

    Generate Change Set

    ↓

    Human Review

    ↓

    Approve

    ↓

    Activate

## Approval Requirements

Review:

-   Source legitimacy
-   Change necessity
-   Metadata correctness
-   Impact

## Rule

Snapshots must not become active without approval.
