# FounderOS Milestone 10 Package README v1.0

## Milestone

**Milestone 10 — Governed Knowledge Context Assembly Foundation**

## Purpose

This package defines the first governed context assembly layer for FounderOS.

Milestone 09 establishes a durable, verified, and recoverable active Knowledge Snapshot. Milestone 10 transforms queries against that active snapshot into deterministic, provenance-preserving, budget-bounded context packages that future AI systems can consume safely.

## Package Contents

1. Milestone specification
2. Context request contract
3. Context package contract
4. Active snapshot binding specification
5. Context selection and ordering policy
6. Context budget and truncation evidence specification
7. Context provenance and omission evidence specification
8. Context fingerprint and reproducibility specification
9. Context evaluation framework
10. Acceptance criteria
11. Verification checklist
12. Codex execution prompt

## Non-Goals

This milestone does not add LLM calls, prompt execution, agent or Hermes runtime, MCP integrations, embeddings, vector databases, semantic ranking, knowledge graph persistence, or UI workflows.
